# Security Policy

## Reporting vulnerabilities

Please report suspected security issues privately by emailing the maintainers through the project contact in the repository metadata or by filing a private advisory through the GitHub Security tab.

## Scope

This project intentionally stores nature observations locally first and avoids unnecessary telemetry. Please do not expose secrets or credentials in public issues.

## Expectations

- Keep dependencies up to date
- Do not commit API keys or personal data
- Validate file uploads and user-supplied content
- Preserve user privacy in local-first storage and sync logic
