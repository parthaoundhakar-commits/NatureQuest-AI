# Contributing

Thanks for contributing to NatureQuest AI.

## Ways to contribute

- Improve frontend interactions or accessibility
- Add new quest categories or locale translations
- Enhance offline handling and error states
- Improve tests for backend and UI flows
- Document local AI model setup and hardware requirements

## Local setup

- Create a branch from `main`
- Run the frontend and backend as described in the README
- Ensure tests still pass before opening a PR
- Keep new features consistent with the local-first and privacy-first design goals

## Contributor guidelines

- Favor local-first and privacy-preserving solutions
- Do not add paid cloud-only AI fallbacks as a core requirement
- Avoid claims about real environmental impact without clear evidence
- Keep model-provider adapters modular and configurable
